CinemaView

Know your view before you book.

CinemaView is an interactive cinema seat-view prototype. Pick a seat on the map and a 3D model of the auditorium walks the camera to that row, sits you down, and lets you look around 180° each way. Every seat gets a view score so you can compare before you pay.

Prototype. The seat layout, prices and availability are sample data. Not an official site of any cinema.

Features
First-person seat view. Tap a seat and the camera walks in from the aisle and sits down. Drag or swipe to look around 180° left and right, pinch or scroll to zoom, reset any time.
200-seat hall in 3D. Raked floor, aisles, leather seats, side panels, speakers, projector beam, and an audience in the taken seats so you can see what blocks the screen.
View score. An estimated 0–100 score per seat from distance, horizontal and vertical angle, screen coverage and heads in front. A recommendation, not a guarantee.
Seat comparison. Put two seats side by side with a still of each view.
Showtime listing. Movies, formats (Atmos, Screen 2, 3D), filters and availability colours.
Your own screen image. Add any picture to the 3D screen.
Mock booking. Review, details, confirmation with a booking ID. No payment.
Mobile first. A 9:16 seat view and a swipeable seat map.
Run it

It is a single HTML file. Open index.html in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → main / root) to host it.

Built with

HTML, CSS, JavaScript and Three.js (r128, loaded from a CDN). No build step.
